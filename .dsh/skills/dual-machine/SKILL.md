# 多机协同（扩展点，不在内核实现）

AOS 单机自洽：八目录宪章与全部 skills 都不依赖第二台机器。需要多机协同时，把它当扩展点对待：

- **状态一致性**：跨机只同步「叙事层」与状态区——06_LOGS、04_MEMORY、09_REFERENCE；过程细节留在各机 harness 会话档案，不同步
- **命令通道**：跨机操作走受控通道（SSH/远程执行工具），降级手动操作须显式记录；引号与编码是跨机命令的高发事故点
- **部署门禁**：任何一端的部署/修改动作，先核对目标机约束（磁盘/服务/端口/运行时数据禁区）再执行
- **环境对齐**：各端跑 `python scripts/align_environment.py`，以 `.dsh/skill-manifest.json` 的 pin 字段对齐组件版本

设计方案与取舍讨论见 `docs/design-rationale.md`「多机协同扩展点」。本发布包不附带跨机脚本。
